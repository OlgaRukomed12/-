# Семейный бюджет

Бесплатный веб-калькулятор для планирования семейного бюджета. Сайт работает полностью в браузере — без сервера, регистрации и передачи данных.

## Возможности

- Приветственный лендинг с описанием сервиса
- Расчёт доходов, расходов, остатка и рекомендуемых накоплений
- Прогресс-бар доли расходов от дохода
- Таблица расходов по категориям с процентами
- Текстовый анализ и рекомендации
- Светлая и тёмная тема с сохранением выбора

## Структура проекта

```
├── index.html          # Главная страница (лендинг + калькулятор)
├── css/
│   ├── variables.css   # CSS-переменные тем
│   ├── layout.css      # Шапка, подвал, общие стили
│   ├── landing.css     # Стили лендинга
│   └── calculator.css  # Стили калькулятора
├── js/
│   ├── theme.js        # Переключение темы
│   └── calculator.js   # Логика расчётов
└── README.md
```

## Запуск

Откройте `index.html` в любом современном браузере:

```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

Или запустите локальный сервер (опционально):

```bash
npx serve .
```

## Технологии

- HTML5
- CSS3 (переменные, адаптивная вёрстка)
- Vanilla JavaScript (без фреймворков)
